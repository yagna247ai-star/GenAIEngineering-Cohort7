### Commit Command Ordering — Ship It Right

Arrange the Git commands in the order that takes a fresh edit to the shared Remote: edit → add → commit → push. Type the four keywords in order, space-separated (e.g. edit add commit push). Also try the pull-before-push variant: pull variants use the same words.

Your order: Check Hint

Hint: Canonical flow → edit in Working Directory → git add to Staging → git commit to Local → git push to Remote. If Remote moved, insert git pull before push.
