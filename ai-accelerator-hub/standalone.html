SESSION 01 • FOUNDATIONS — JOURNALISM FOCUS

Foundations of Generative AI and the AI Generalist Toolkit

For journalists, generative AI is not a chatbot. It is a generalist toolkit — models + prompts + context + evals — that turns reporting labor into verifiable systems.

01 — The Generalist Reporter LensCompose LLM, retrieval, human judgment like a desk: researcher + drafter + standards editor. Tip → Retrieval → Draft → Gate → Publish.
02 — Prompt Engineering vs Context EngineeringPrompt = precise instruction. Context = evidence window. Reliability lives in context; leverage in prompt.
03 — Editorial GuardrailsEvery output carries citations + confidence (high/med/low) + Do-not-publish checklist. Verification is the product.
