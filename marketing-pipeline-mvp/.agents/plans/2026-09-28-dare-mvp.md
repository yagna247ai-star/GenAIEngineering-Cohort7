## Goal
Build Marketing Pipeline MVP - Lead-to-Meeting AI Agent - inside uv project `marketing-pipeline-mvp/` following D.A.R.E framework (Sandeep Swadia, Kore.ai)

## Success Criteria
1. One live Agent handling UC1+UC3 end-to-end (FastAPI simulation of Kore.ai XO + Search AI + Agent AI)
2. 30% reduction Lead Response Time OR 20% MQL->SQL lift vs baseline
3. Integrated with CRM (HubSpot adapter, Salesforce swappable) + 1 channel Web/WhatsApp mock
4. Runnable in project-local venv: `marketing-pipeline-mvp/.venv` (Python 3.11) via `UV_CACHE_DIR=/tmp/uv-cache uv run` or `./.venv/bin/python`
