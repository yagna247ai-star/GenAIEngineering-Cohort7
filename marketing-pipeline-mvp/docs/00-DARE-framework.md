# D.A.R.E Framework - Sandeep Swadia (Kore.ai)

> Source: Kore.ai Enterprise AI Transformation methodology - Discover, Architect, Realize, Expand

## Overview
D.A.R.E is the Kore.ai delivery framework championed by Sandeep Swadia to take AI from POC to Production without getting stuck. It's used for every Kore.ai XO / Agent AI deployment.

## The 4 Phases

### D - DISCOVER (Week 1)
**Goal:** Find the *right* problem, not just any AI idea.
- **Activities:** Business discovery workshops, funnel audit, stakeholder interviews, process mining
- **Inputs:** CRM dump, sales call transcripts, website analytics, Martech stack map
- **Outputs:** Prioritized use-case backlog, BANT/ICP definition, Success metric (e.g., MQL->SQL %)
- **Kore.ai Artefacts:** Use-Case Canvas, Value vs Feasibility matrix, Conversation mining report
- **Gate:** Use-case approved with measurable KPI and data availability confirmed

### A - ARCHITECT (Week 2)
**Goal:** Design how AI + Human + System orchestrate.
- **Activities:** Experience design, conversation flow storyboard, data & integration architecture, guardrails
- **Outputs:** 
  - Dialog flows (Kore.ai XO Storyboard)
  - Entity & knowledge model (Search AI RAG)
  - Integration spec (HubSpot/Salesforce, WhatsApp, Calendar)
  - Scoring & handoff logic
  - Governance (PII, hallucination controls)
- **Gate:** Architecture sign-off + integration credentials available

### R - REALIZE (Week 3-4)
**Goal:** Build the smallest *valuable* slice and prove live.
- **Activities:** Agile build in Kore.ai XO Platform, RAG ingestion, API integration, UAT with real data
- **Principle:** 1 Use-Case End-to-End > 5 half-built demos
- **Outputs:** Working Agent on dev, test conversations, pilot on 20% traffic
- **Gate:** Pilot metrics hit threshold (e.g., >85% intent accuracy, meeting booked)

### E - EXPAND (Week 5+)
**Goal:** Scale, govern and evolve to platform.
- **Activities:** Rollout to 100% traffic, add next use-case, monitoring dashboard, feedback loop
- **Outputs:** Admin analytics, retraining pipeline, playbook for next team
- **Metrics:** CSAT, containment rate, pipeline velocity, ROI

## Why This Matters for Marketing Pipeline MVP
Most marketing AI fails in Discover (wrong use-case) or Realize (never ships). D.A.R.E forces:
1. Value-first use-case selection (not tech-first)
2. Architecture before build (so integration doesn't block you later)
3. Realize with live data (not synthetic demo)
4. Expand only after proof (so you don't over-engineer MVP)
